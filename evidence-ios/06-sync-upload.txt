## D. iMessage / Email / Apple Notes ingestion (no private API; via user-built Shortcuts automations)
  App Intents (Metadata.appintents): HCHForwardIMessageToHatchAppIntent(content, sender, senderName,
  recipients) and HCHForwardEmailToHatchAppIntent(subject, emailContent, sender), openAppWhenRun=false.
  - Almost anyone: leave "Sender" empty and type a single space into "Message Contains". Shortcuts will not save a trigger with no criteria, and nearly every message has a space 
  Apple iMessage (Beta)
  Forward new messages with an Apple Shortcuts automation.
  HCHCapturedIMessageStore
  Incoming messages forwarded by a user-created Apple Shortcuts automation. No message history access. iOS cannot detect removal of the automation; disconnect in the iMessage connector to stop forwarding.
  Install the shortcut, then create a Messages automation. You choose which messages it forwards.
  Notes exports will stay on this device until Notes sync is available for your account.
  Set up Mail shortcut
  Share a text copy of all your Apple Notes with Muse whenever your shortcut runs. Turning this off stops future exports from your automations.
  This prototype needs the Notes export shortcut installed separately, named {FBTParam|shortcutName}. Run it manually, or add a Time of Day or Notes app Is Closed automation in Shortcuts. Choose Run Immediately when available. Exports upload when Muse can connect; open Muse if an export is waiting.
  To stop iMessage reads when the user asks to disconnect or stop syncing messages, set `disable_forwarding: true`. This discards queued messages and blocks future forwarding on this device. Previously uploaded messages are not deleted. The user can also disable or delete the automation in Apple's Shortcuts app.
  You decide which messages the automation forwards when you build it. Turn forwarding off here or delete the automation in Shortcuts at any time. Messages already shared are not deleted.
  => PROVEN: iMessages/emails are captured only if the user builds a Shortcuts "Message"/"Email"
     automation that calls the intent; the agent-facing guidance tells the model how to walk users
     through a catch-all trigger (single space in "Message Contains" = nearly all messages).
     Apple Notes: a "Notes export" shortcut sends a text copy of ALL notes each run.
     Uploaded messages are "not deleted" when forwarding is disabled (verbatim).
