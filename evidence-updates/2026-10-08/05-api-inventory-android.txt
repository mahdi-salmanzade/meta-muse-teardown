Method: static only. ripgrep over decompiled Java/Kotlin (aura package, obfuscated X/ package,
  shared com/facebook libraries) for absolute URL literals, wss:// literals, relative API path
  literals (StefiHatchPath.java, StefiMusePath.java, JarvisPath.java, HatchUrlSegments.java,

  Every finding was diffed mechanically against the Android 8.0.0.21.168 decompilation
  (extracted-apk/jadx) so NEW/REMOVED markers are version diffs, not memory.
  Nothing was installed, executed or network-contacted.

LIMITATION: static strings != observed traffic. A hostname, URL, method or field name in code
shows capability, not behaviour; it does not prove a connection is made, when, or what is sent.
Server-side MobileConfig flags (MC.*) can switch many paths on or off. Secrets/keys are shown
redacted (first chars + length). Prior-version inventory: evidence-android/16-network-android.txt
(Android 8.0.0.21.168); this file supersedes its endpoint lists and marks every entry
NEW (first appears in 9.0), REMOVED (present in 8.0, gone in 9.0), or unchanged.

Markers: [NEW] = first appears in 9.0.0.23.178 (verified 0 hits in the 8.0 decompilation AND
8.0 native strings). [REMOVED] = in 8.0, absent from 9.0. [undoc-8.0] = already present in 8.0
but NOT enumerated in the prior inventory doc (so "new to the record", not new to the app).
No marker = documented in the prior inventory and unchanged.
