6. NOTABLE TENSIONS VISIBLE IN TEXT ALONE
======================================================================

  - Calendar consent says information "shared after you connect" (W@42161232), but a native agent tool
    can "Publish a historical local-source window" for calendar (N@12262352), and native copy ties "full
    history" upload to automatic syncing (N@12365872). Contacts copy says existing information is stored
    (W@42160958).
  - Mail auto-sync shares "who new email is from and what it is about" (sender + subject)
    automatically (W@42164742). No macOS copy mentions filtering one-time codes in subjects.
  - The approval default stored as `auto_allow` is labelled "Ask for some actions" (W@44936673).
  - Deletion is described as asking the agent ("You can ask the agent to delete stored information"),
    not as a settings control; disconnecting does not remove earlier data (W@20718706).
